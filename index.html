Flagship project

Integrated Omics Workflow Platform

A modular collection of scientific APIs exposed through two independent access paths: an interactive Dash application and reproducible Nextflow DSL2 pipelines.

Current platform

From uploaded data to organized, reviewable results

The platform brings bulk RNA-seq, single-cell RNA-seq, CRISPR Mixscape, enrichment-network analysis, and LLM-assisted triage into a shared API ecosystem. Users can work interactively through Dash or run automated, resumable workflows through Nextflow.

  • Two independent access paths: an interactive Dash application and automated Nextflow DSL2 pipelines.
  • Shared FastAPI services with modular endpoints, input validation, job tracking, and structured result delivery.
  • Dash-based analysis for submitting individual jobs, checking status, and reviewing outputs interactively.
  • Nextflow-based orchestration for chaining API-backed analyses into resumable end-to-end workflows.
  • Organized result bundles containing analysis outputs, networks, triage reports, manifests, and workflow reports.
  • Container-oriented design supporting reproducibility across local, cloud, and HPC-style environments.
